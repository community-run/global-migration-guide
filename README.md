# 全球移居生活指南

**世界很大，让当地经验带路。**

[访问社区](https://global-migration-community.kohakuqing.chatgpt.site/) · [社区工作台](https://global-migration-community.kohakuqing.chatgpt.site/admin)

## 为什么做这份指南？

让真实的经历，帮后来的人少走弯路。

网上不缺移民信息，但一条消息经过层层转述和包装，往往只剩下最美好的那一面。条款怎么写、当地怎么执行、落到自己身上能不能办成，中间可能隔着许多没有被说清楚的条件。

一个国家的日常生活，也可能被加上滤镜。有了可行的移居路径，自己和家人能不能适应那里的生活，仍是另一个需要认真了解的问题。真实的生活成本、语言环境、文化差异，以及那些镜头之外的日常，都值得在出发前听听当地人的亲身经历。

有人看到一篇让人心动的介绍，或者一项新法案，就开始安排另一种生活。等真正到了当地、着手办理，才发现还有没被提到的条件和问题。时间花了，钱也花了，有些选择已经很难回头。

所以，我很珍惜那些愿意把具体情况、办理过程和踩坑经历写下来的人。他们的内容也许没有多少浏览量，却可能帮一个人避开一个大坑，省下几个月的时间和一笔辛苦钱。

我想做这个社区，就是想让这些有价值的经验留下来，让需要它的人找得到。

我们会保留作者和原文链接，注明时间、地区与适用条件，用 AI 协助整理，再由熟悉当地法规、政策和实际情况的社区核验员审核后直接发布。让当地人继续补充，让经历过的人随时纠错，把散落各处的经验，慢慢整理成一份持续更新的移居生活指南。

这里拒绝中介获客、代办推广与佣金导流。我们希望每一次分享，都能帮助一个人把情况看得更清楚。

不一定要写长文。一条亲历、一个提醒、一次纠错，都有价值。也许你认真写下的几句话，正是另一个人做决定前，最需要看到的信息。

## 现在可以做什么

- 无需登录分享 X、抖音、TikTok、YouTube 原始链接，投稿保存到审核队列。
- 阅读核验员发布的摘要、核心点与原创文章，按国家查看，回到原作核对。
- 每篇文章都可提交纠错；愿意继续共建时可自愿留下联系方式，仅管理员可见。
- 登录并申请成为当地共建者或核验员；管理员审核在地经历并按国家授权。
- 核验员可直接发布所负责国家的他人内容，保留草稿、公开版本与操作记录。
- 管理员维护国家指南、评分依据与相关当地分享。

AI 配置完成后才会启用自动整理。只整理实际读取或补充的正文/字幕，来源无法读取时进入待补充队列。X 公开正文与 YouTube 字幕读取受平台可访问性影响；抖音、TikTok 暂需补充文稿。摘要不替代原作，不凭标题编写结论。

## 一起共建

欢迎通过 [Issues](https://github.com/community-run/global-migration-guide/issues) 推荐移居相关原始链接、提交纠错或补充当地经验。请注明国家、城市、事情发生时间、适用条件及原始来源；不清楚的地方请直接说明。申请成为当地共建者，须当前在当地，或曾长期居住且熟悉实际情况；共建与核验资格由社区管理员审核。

公开 Issue 不要填写微信号、电话、证件、住址或当事人隐私。我们拒绝中介获客、代办推广、保证结果和佣金导流。收录不代表原作者入驻；原作者作品仍归原作者所有。

## 发布范围

GitHub Pages 保留社区入口，投稿、审核与纠错由带数据库的完整社区处理。本仓库的公开文件不包含私密联系方式、内部完整转录稿、运行凭据或日志。
