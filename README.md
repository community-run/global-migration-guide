# 当地人说

听过来人说，再决定去哪里。

这是一个华人移居互助社区。在各国生活的华人分享办身份、过日子、孩子上学这些事的真实经历，核验后整理成按国家分类的指南。

## 为什么做这份指南？

让真实的经历，帮后来的人少走弯路。

网上不缺移民信息，可一条消息转了几手，往往只剩下好听的部分。政策条文怎么写是一回事，当地实际怎么办、放到自己身上能不能办下来，又是另一回事，中间很多条件没人讲清楚。

当地的日子也容易被美化。就算身份办得下来，自己和家人能不能在那里过得惯，还得另外打听。生活要花多少钱，语言通不通，平时过得怎么样，这些最好出发前问问在那边生活的人。

有人看了一篇介绍、或者一条新政策的消息，就开始准备搬家。到了当地真正去办，才发现有些条件之前没人提过。时间和钱都花出去了，有的决定已经没法回头。

所以我特别感谢那些愿意把自己的情况、办理过程和踩过的坑写出来的人。这些内容可能没多少人看，但对正好需要的人来说，也许就能少走几个月弯路，省下一笔钱。

我做这个社区，是想把这些经验留下来，让需要的人找得到。

每条内容都会保留作者和原文链接，写明时间、地区和适用条件。整理时会用 AI 帮忙，再由熟悉当地法规和实际情况的核验员看过才发布。之后当地人可以接着补充，有过经历的人发现不对也可以随时纠正。这些零散的经验会慢慢攒成一份一直在更新的移居指南。

这里不接中介获客、代办推广和佣金导流。

想分享的话，不用写长文。说一件自己经历过的事，提醒一句，或者指出一处错误，都很有用。你认真写下的几句话，也许正是另一个人做决定前最需要看到的。

## 社区怎么运作

先是收集经历。任何人都可以贴一条抖音、小红书、微信公众号、B 站、YouTube、TikTok 或 X 的链接。如果写的是自己的事，可以顺便补上城市、时间、身份（居留、永居还是入籍）、签证类型和家庭情况。

然后整理和核验。AI 只根据实际读到的原文或字幕提炼要点，再由熟悉当地情况的核验员核对来源、时间、地点和适用条件，没问题才发布。

最后汇成国家指南。居留、永居、入籍、生活成本、孩子上学、看病，还有政策写的和实际办的差在哪里，每一部分都会注明参考了哪几条经历。大家说法不一样的，就把几种说法并排放出来。

## 不用登录就能做的事

- 第一次进站时选一个身份。之后你的分享、提问和回答会带上「自述」标签，别人看了就知道这条经验适不适合自己。
- 分享一个链接，再补几句背景。
- 在问答区提问或回答，看到有用的回答可以点「有帮助」。
- 看到和自己差不多的经历，点「我也遇到过」。情况不一样，就写下「我的情况不一样」，审核后会和原文放在一起。
- 纠错，或者补充最新情况。原作者可以认领署名，也可以申请下架。

想成为当地共建者需要登录。共建者可以写原创，回答会直接显示，也能参与核验。管理员会按国家审核申请人在当地的生活经历。

## 一起共建

也欢迎在 [Issues](https://github.com/hearlocals/hearlocals/issues) 推荐移居相关的原始链接、指出错误或补充当地情况。请写明国家、城市、事情发生的时间、适用条件和原始来源，不确定的地方直接说就行。

请不要在公开的 Issue 里留微信号、电话、证件、住址或别人的隐私。这里不接中介获客、代办推广、保证结果和佣金导流。收录一篇内容不代表原作者已经入驻，作品版权仍归原作者。
