## 为什么做这份指南？

让真实的经历，帮后来的人少走弯路。

网上不缺移民信息，但一条消息经过层层转述和包装，往往只剩下最美好的那一面。条款怎么写、当地怎么执行、落到自己身上能不能办成，中间可能隔着许多没有被说清楚的条件。

一个国家的日常生活，也可能被加上滤镜。有了可行的移居路径，自己和家人能不能适应那里的生活，仍是另一个需要认真了解的问题。真实的生活成本、语言环境、文化差异，以及那些镜头之外的日常，都值得在出发前听听当地人的亲身经历。

有人看到一篇让人心动的介绍，或者一项新法案，就开始安排另一种生活。等真正到了当地、着手办理，才发现还有没被提到的条件和问题。时间花了，钱也花了，有些选择已经很难回头。

所以，我很珍惜那些愿意把具体情况、办理过程和踩坑经历写下来的人。他们的内容也许没有多少浏览量，却可能帮一个人避开一个大坑，省下几个月的时间和一笔辛苦钱。

我想做这个社区，就是想让这些有价值的经验留下来，让需要它的人找得到。

我们会保留作者和原文链接，注明时间、地区与适用条件，用 AI 协助整理，再由熟悉当地法规、政策和实际情况的社区核验员审核后直接发布。让当地人继续补充，让经历过的人随时纠错，把散落各处的经验，慢慢整理成一份持续更新的移居生活指南。

这里拒绝中介获客、代办推广与佣金导流。我们希望每一次分享，都能帮助一个人把情况看得更清楚。

不一定要写长文。一条亲历、一个提醒、一次纠错，都有价值。也许你认真写下的几句话，正是另一个人做决定前，最需要看到的信息。

## 社区怎么运作

先是收集经历。任何人都可以贴一条抖音、小红书、微信公众号、B 站、YouTube、TikTok 或 X 的链接。如果写的是自己的事，可以顺便补上城市、时间、身份（居留、永居还是入籍）、签证类型和家庭情况。

然后整理和核验。AI 只根据实际读到的原文或字幕提炼要点，再由熟悉当地情况的核验员核对来源、时间、地点和适用条件，没问题才发布。

最后汇成国家指南。居留、永居、入籍、生活成本、孩子上学、看病，还有政策写的和实际办的差在哪里，每一部分都会注明参考了哪几条经历。大家说法不一样的，就把几种说法并排放出来。

## 不用登录就能做的事

- 第一次进站时选一个身份。之后你的分享、提问和回答会带上「自述」标签，别人看了就知道这条经验适不适合自己。
- 分享一个链接，再补几句背景。
- 在问答区提问或回答，看到有用的回答可以点「有帮助」。
- 看到和自己差不多的经历，点「我也遇到过」。情况不一样，就写下「我的情况不一样」，审核后会和原文放在一起。
- 纠错，或者补充最新情况。原作者可以认领署名，也可以申请下架。

想成为当地共建者需要登录。共建者可以写原创，回答会直接显示，也能参与核验。管理员会按国家审核申请人在当地的生活经历。

## 一起共建

也欢迎在 [Issues](https://github.com/hearlocals/hearlocals/issues) 推荐移居相关的原始链接、指出错误或补充当地情况。请写明国家、城市、事情发生的时间、适用条件和原始来源，不确定的地方直接说就行。

请不要在公开的 Issue 里留微信号、电话、证件、住址或别人的隐私。这里不接中介获客、代办推广、保证结果和佣金导流。收录一篇内容不代表原作者已经入驻，作品版权仍归原作者。
