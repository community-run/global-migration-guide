## 为什么做这份指南？

让真实的经历，帮后来的人少走弯路。

网上不缺移民信息，但一条消息经过层层转述和包装，往往只剩下最美好的那一面。条款怎么写、当地怎么执行、落到自己身上能不能办成，中间可能隔着许多没有被说清楚的条件。

一个国家的日常生活，也可能被加上滤镜。有了可行的移居路径，自己和家人能不能适应那里的生活，仍是另一个需要认真了解的问题。真实的生活成本、语言环境、文化差异，以及那些镜头之外的日常，都值得在出发前听听当地人的亲身经历。

有人看到一篇让人心动的介绍，或者一项新法案，就开始安排另一种生活。等真正到了当地、着手办理，才发现还有没被提到的条件和问题。时间花了，钱也花了，有些选择已经很难回头。

所以，我很珍惜那些愿意把具体情况、办理过程和踩坑经历写下来的人。他们的内容也许没有多少浏览量，却可能帮一个人避开一个大坑，省下几个月的时间和一笔辛苦钱。

我想做这个社区，就是想让这些有价值的经验留下来，让需要它的人找得到。

我们会保留作者和原文链接，注明时间、地区与适用条件，用 AI 协助整理，再由熟悉当地法规、政策和实际情况的社区核验员审核后直接发布。让当地人继续补充，让经历过的人随时纠错，把散落各处的经验，慢慢整理成一份持续更新的移居生活指南。

这里拒绝中介获客、代办推广与佣金导流。我们希望每一次分享，都能帮助一个人把情况看得更清楚。

不一定要写长文。一条亲历、一个提醒、一次纠错，都有价值。也许你认真写下的几句话，正是另一个人做决定前，最需要看到的信息。

## 社区怎么运作

1. **收集经历**：任何人都可以贴一条抖音、小红书、微信公众号、B 站、YouTube、TikTok 或 X 链接。分享自己的经历时，可以补充当时的城市、时间、身份（居留 / 永居 / 入籍）、签证路径和家庭情况。
2. **AI 整理，当地人核验**：AI 只依据实际读到的原文或字幕提炼重点；熟悉当地的社区核验员核对来源、时间、地点和适用条件后发布。
3. **汇成国家指南**：居留、永居、入籍、生活成本、孩子教育、医疗、政策与实际执行，每一节都写明依据了哪几条经历；说法不一致时并列展示。

## 现在可以做什么（都不需要登录）

- 首次进站选择自述身份，之后的分享、提问和回答会带上「自述」标签，帮大家判断经验适用于谁。
- 分享链接，并补几句背景。
- 在问答区提问、回答，给有用的回答点「有帮助」。
- 读到相近的经历点「我也遇到过」；情况不同就写下「我的情况不一样」，审核后与原文并列。
- 纠错、补充最新情况；原作者可以认领署名或申请下架。

申请成为当地共建者（写原创、回答直接显示、参与核验）需要登录，由管理员按国家审核在地经历。

## 一起共建

也欢迎通过 [Issues](https://github.com/hearlocals/hearlocals/issues) 推荐移居相关原始链接、提交纠错或补充当地经验。请注明国家、城市、事情发生时间、适用条件及原始来源；不清楚的地方请直接说明。

公开 Issue 不要填写微信号、电话、证件、住址或当事人隐私。我们拒绝中介获客、代办推广、保证结果和佣金导流。收录不代表原作者入驻；原作者作品仍归原作者所有。
